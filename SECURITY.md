# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Crab Launcher** — especially related to account authentication, token storage, file handling, or process execution — please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, report the issue privately using **GitHub Security Advisories** on the repository (`Security` → `Report a vulnerability`), or contact the maintainer directly via GitHub.

Please include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Affected version or commit hash.
- Any suggested fix or mitigation, if available.

We will acknowledge your report as soon as possible and work with you to resolve the issue before any public disclosure.
